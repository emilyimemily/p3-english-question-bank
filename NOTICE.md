# Notice

This repository contains a structured, OCR-derived index of Primary 3 English past-year
examination papers from Singapore schools (2024-2025), compiled for private study and practice.
Question text is reproduced only to the extent needed to identify and practise the item.

- School and paper names are used for attribution only; no endorsement is implied.
- The corpus is not affiliated with, or approved by, any school or examination authority.
- Because the source is OCR, some text may be inaccurate. Items flagged `needs_review` are
  explicitly marked as unverified.
- If you represent a rights holder and would like any content removed, please open an issue in
  this repository and it will be taken down promptly.

`robots.txt` currently allows indexing. To opt out of search-engine indexing, change it to
`Disallow: /` and push the change; note that already-cached copies are outside the control of
this repository.
